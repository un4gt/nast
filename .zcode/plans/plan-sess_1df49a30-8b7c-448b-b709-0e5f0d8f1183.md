# 前端三栏布局重构方案（按 web-design.md）

## 目标形态

```
┌──────────────┬───────────────────────────┬──────────────────┐
│ 左侧栏        │ 中央聊天（主体）            │ 右侧 Inspector    │
│ Characters   │ 极简头：头像+名字            │ Character        │
│ Chats(Today/…)│ 消息流（气泡/流式/swipe）    │  Overview/Persona │
│ (Groups 占位) │ 输入条（swipe/重生成/续写/代入）│ World Info       │
│ Settings     │                            │ Author Note      │
│              │                            │ Generation       │
│              │                            │ (Preset 占位)     │
└──────────────┴───────────────────────────┴──────────────────┘
```

- 左右两栏**常驻、可收起**（收起后变成细图标栏），收起状态持久化到 localStorage。
- 右栏 Inspector 内容用分组折叠；**第一期只用现有 RPC/参数**，Preset/Memory 显示「即将支持」占位。
- 中央聊天区保留现有全部能力（气泡/双击编辑/流式/swipe 导航/重生成/续写/代入/停止），从 App.tsx 拆成独立文件。

## 文件改动

### 新增
1. `web/src/components/layout/LeftSidebar.tsx` — 基于**已安装但未使用**的 shadcn `sidebar.tsx` 组件（SidebarProvider 提升到 App）：
   - SidebarHeader：连接状态
   - SidebarGroup「Characters」：头像+名字菜单项（现 Sheet 内容迁入）；底部「导入角色卡」按钮 + 隐藏 file input
   - SidebarGroup「Chats」：按 `send_date` 分 Today/Yesterday/Earlier 分组（数据来自 `characters.chats` + 新增 action `openChat(file)` 直接 `chats.get` 指定文件——后端已支持，仅前端缺 action）；当前聊天高亮
   - SidebarFooter：「设置」入口 + Groups 占位项（disabled，tooltip「即将支持」）
2. `web/src/components/inspector/RightInspector.tsx` — 右栏容器：细图标轨道（Character/BookOpen/PenLine/Brain/SlidersHorizontal 五个图标）+ 内容区按选中图标切换；顶部 collapse 按钮收起到图标栏。
3. Inspector 面板组件（同目录）：
   - `CharacterPanel.tsx` — Overview（名字/标签/描述只读+折叠展开）、Persona（textarea 编辑 `persona_description`，存 localStorage 并随 `generate.run` params 发送——RPC 已支持该参数，前端目前写死空串）、卡片元数据只读展示
   - `WorldInfoPanel.tsx` — 当前角色绑定书（`data.extensions.world`）的只读条目列表 + 「打开世界书管理」按钮（复用 WorldEditor Dialog）；书选择 Select
   - `AuthorNotePanel.tsx` — note_prompt/note_depth/interval 编辑，存 localStorage，随 generate params 透传（generate.rs 已把 chat_metadata 的 AN 路径留给后续；第一期先作为 `quiet`-less 注入参数 `in_chat_injections` 由前端随请求发送——generate.run params 已兼容）
   - `GenerationPanel.tsx` — 复用 SettingsDialog 的 SliderField/SwitchField 模式（抽出为 `web/src/components/settings/fields.tsx` 共享），直接编辑 settings.oai_settings 并保存
   - Preset/Memory 面板占位（Empty 组件）
4. `web/src/components/chat/ChatArea.tsx`、`MessageBubble.tsx`、`StreamingBubble.tsx`、`SwipeControls.tsx`、`ChatInput.tsx` — 从 App.tsx 原样迁出（含双击编辑、流式、停止）
5. `web/src/components/chat/ChatActionsMenu.tsx` — 原样迁出

### 修改
- `App.tsx` — 重写为组合层：SidebarProvider + LeftSidebar + 中央 ChatArea/Empty + RightInspector；顶栏合并进左栏（去掉独立 header）；drag-drop 保留在中央区
- `store.ts` — 新增：`openChat(file)`（指定聊天文件）、`personaDraft`/`setPersonaDraft`、`anDraft`/`setAnDraft`、`send()` 的 params 组装点扩展（persona_description/an injections 从 draft 读取）；`chatList` 增强为带 last_modified（后端 characters.chats 返回文件名列表，第一期用文件名内时间戳排序即可，无需后端改动）
- `tailwind`/`index.css` — 无结构性改动，仅按需微调

### 删除
- App.tsx 中的左 Sheet 角色列表（迁入 LeftSidebar）、独立 header

## 关键实现约束

- **不加后端改动**（第一期）：persona/AN 第一期走「前端草稿 + generate.run 参数」路径；UI 上注明「暂存于本地，聊天元数据持久化后续版本」。Inspector 的 Character 面板卡片字段只读（`characters.edit` RPC 留到第二期）。
- 复用已安装未用的 shadcn 组件：`sidebar`（左栏）、`card`（Inspector 面板）、`accordion`（需 `npx shadcn add accordion`，仅此一个新组件）、`alert-dialog`（删除确认，顺带接入删除角色/删除聊天）。
- 保留 `use-mobile` hook；移动端折叠行为不做专门适配（用户已声明不考虑）。
- 消息流/swipe/流式逻辑**不改行为**，仅迁移文件。
