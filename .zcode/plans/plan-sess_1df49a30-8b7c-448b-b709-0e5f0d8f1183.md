# nast — Not A SillyTavern 实施计划（依据 ST 1.18.0 实测源码修订）

## 0. 目标与原则

把 ST 浏览器端核心逻辑全部移入 Rust 服务端（行为语义重写，非逐行移植）：Generate 流程（字符串类型 normal/continue/impersonate/swipe/regenerate/quiet）、sendMessageAsUser、swipe、群聊调度、正则、宏、世界书引擎、Author's Note、persona、eventSource→WS 事件总线。前端（react+shadcn+rsbuild）只做视图/编辑器，单端口 WebSocket 通信。数据层与 ST 1.18.0 完全同构，导入导出直接兼容。模型接入仅 chat-completions 类：OpenAI 兼容(baseURL 可配)/Anthropic/Gemini。范围外：文本补全路径（instruct/context 模板）、向量/RAG、图像生成、TTS、翻译、多用户。

## 1. 参照基准

本地已有 `refrence/SillyTavern`（release 1.18.0，HEAD 8172dcd0），作为唯一行为对照基准（gitignore，禁止 copy 代码）。研究阶段已产出三份源码级行为报告（Generate/流式、PromptManager/宏、世界书/群聊/正则/卡片/存储），其结论作为实施契约，实现时按行号回源码核对。

## 2. 仓库结构（Cargo workspace + web/）

```
nast/
├── Cargo.toml            # workspace
├── crates/
│   ├── nast-model/       # serde 类型（ST 1.18.0 同构）：卡V1/V2/V3、WI entry、消息（extra.reasoning* 等）、chat_metadata、settings、group、persona、regex script、prompt preset
│   ├── nast-cards/       # PNG tEXt chunk(chara/ccv3, base64) 自实现读写、卡规范化/校验
│   ├── nast-storage/     # data/<user>/ 布局、jsonl 聊天 IO、原子写、integrity、节流备份
│   ├── nast-engine/      # 宏引擎（旧版有序 pass 语义为基准）、世界书引擎、正则引擎、ChatCompletion+TokenHandler 拼装、群聊调度、token 计数(tiktoken-rs+近似)
│   ├── nast-providers/   # OpenAI兼容/Anthropic/Gemini + 统一 StreamEvent 归一化 + abort
│   ├── nast-plugin/      # mlua 插件：事件钩子 + 数据访问
│   └── nast-server/      # actix-web + actix-ws 单端口：WS RPC、会话状态机、生成流水线编排、静态托管
└── web/                  # rsbuild + react + tailwind + shadcn/ui + zustand
```

依赖：actix-web + actix-ws（单端口同进程）、tokio、reqwest(stream)、serde/serde_json、mlua(lua54 vendored)、regex、uuid、chrono、base64、tiktoken-rs、thiserror、tracing。PNG tEXt 自实现（~150 行，只认 tEXt 非 zTXt/iTXt）。

## 3. 服务端架构

- 单端口 8000：`GET /`静态资源、`POST /upload/*`文件上传、`GET /ws`升级 WebSocket。
- WS 协议（JSON）：`{id, method, params}` 请求；`{id, result|error}` 响应；`{event, data}` 广播。事件名复用 ST 语义：generation_started/GENERATION_AFTER_COMMANDS/message_sent/user_message_rendered/message_deleted/group_member_drafted/generate_after_data/stream_token_received/message_received/character_message_rendered/impersonate_ready/generation_stopped/generation_ended/message_swiped/message_updated/chat_id_changed 等（大小写按 ST 原样）。
- 会话状态：单用户全局 AppState（RwLock + 生成 mpsc，同时刻一个生成，双 abortController 语义：全局停止 + 流式 fetch 各一）。
- 生成状态机：用户消息先落盘（MESSAGE_SENT）→宏→WI→正则(prompt pass)→ChatCompletion 拼装→token 预算→provider 流式→STREAM_TOKEN 广播→swipe_info/extra 写入→正则(display pass)→落盘→MESSAGE_RECEIVED。错误不写入消息文本（toast 事件），流式保留半截文本。
- 类型语义（1.18.0）：swipe 弹出被重roll消息、原地写 swipes[swipe_id]+swipe_info、每 swipe 独立 send_date、setFirstSwipe 镜像；regenerate 先删最后一条再生成；impersonate 结果入输入框（IMPERSONATE_READY）不落消息；quiet 返回字符串不落消息不流式；continue 双模式（nudge 加末尾 vs Claude prefill）。

## 4. 兼容契约（对照 refrence/ 源码逐条实现）

**数据**：PNG tEXt `chara`/`ccv3`(后者优先)；V1 导入合成 data.extensions（talkativeness 字符串、depth_prompt{depth:4,role:'system'}、world、fav）；文件名 sanitized.png 冲突加后缀；无索引（扫描目录）。聊天 `chats/<char>/<name>.jsonl` 首行 header{user_name:'unused',character_name:'unused',chat_metadata}，群聊 `group chats/<humanizedDateTime>.jsonl`；integrity uuid 校验(400 unless force)；备份节流 10s；groups/<uuid>.json 含 chats[]+chat_id；书为 {entries:{uid:entry}}。

**拼装（nast-engine）**：prompt_order 全局 dummy 100001（Default.json 双列表并存，取 100001）；ChatCompletion 语义：预算=context−max_tokens、先 reserve 3（assistant priming）+new-chat+groupNudge+续写+控制提示；历史从新到旧填充、**首条塞不下即断**；强制集合超限报错；`[Start a new Chat]` 无条件插历史开头；marker 填充（worldInfoBefore/After 用 wi_format 包裹、personality/scenario format、persona 仅 IN_PROMPT 位置、卡片覆盖 main/jailbreak 需 forbid_overrides 检查）；ABSOLUTE 注入：深度从末尾数、order 组降序处理最终升序呈现、角色 system→user→assistant、扩展 IN_CHAT 仅入 order-100 桶；injection_trigger 按生成类型字符串门控；squash_system_messages（排除 newMainChat/newChat/groupNudge）；names_behavior -1/0/1/2；continue_postfix 默认空格；Claude 转换（仅前导 system 提取、merge/semi/strict/single 后处理、占位 "Let's get started."、assistant prefill trimEnd）；宏多 pass（char/user/persona/description/personality/scenario/random 每次重roll/pick 确定性/roll/setvar·getvar·addvar·inc·dec/global 系/newline/trim//{{//}}/time·date·weekday·datetimeformat/idle_duration/lastMessage 系/input/model/original/maxContext 等，getvar 不回退全局，setvar 即时持久化）；WI 引擎全量（scan_state 状态机、recursion 全局门、sticky/cooldown/delay 存 chat_metadata.timedWorldInfo["world.uid"]、protected 隔离 swipe、hash 失效、probability、groupOverride/加权随机/group scoring、预算 round(%×context) capped、order 降序迭代+before 块 unshift 翻转、position 0-7 含 @D 字符串/EM 锚点/outlet、/regex/ key 覆盖全局匹配、无 * 通配、激活期宏替换）；正则（placement 0-4、display/prompt 双 pass、minDepth/maxDepth 距底、trimStrings、substituteRegex 0/1/2、全局→角色→聊天链式）；群聊（NATURAL 提及词+talkativeness 随机+禁最后发言者+随机兜底/LIST/MANUAL/POOLED、SWAP/APPEND/APPEND_DISABLED 卡片拼接 join prefix/suffix、成员 depth_prompt、开场白随机、original_avatar、extra.gen_id 批次）；persona 四位置；AN interval 按用户消息数取模。

## 5. 里程碑（每步可运行）

- **M0 骨架+数据层**：workspace；nast-model 全类型+真实 ST 文件 fixture 测试；nast-cards PNG 读写+V1/V2/V3 规范化；nast-storage jsonl/settings/备份/integrity。
- **M1 导入导出跑通**：RPC characters/worlds/settings 全套；前端最小页（角色网格+导入+卡片详情）。验收：直接指向现有 ST 数据目录可用。
- **M2 生成管线**：宏引擎→ChatCompletion 拼装（快照测试对照源码）→providers 三协议+统一 StreamEvent+abort→生成状态机+流式+swipe/impersonate/continue/regenerate+聊天 CRUD；前端聊天视图（发送/流式/swipe/编辑/删除）+AN/persona。
- **M3 世界书+正则**：WI 全引擎表驱动测试；正则引擎+三作用域；WI 编辑器、正则/AN/设置收拢 UI。
- **M4 群聊**：群对象/调度策略/APPEND 合并/群聊天文件/群 UI。
- **M5 插件+打磨**：mlua 插件、屏幕适配、设置收拢、打包。

## 6. 多智能体分工

nast-model 由主线程先行定契约；之后并行：①cards+storage ②宏+拼装 ③providers ④WI+正则 ⑤前端 ⑥群聊。任务书内嵌行为契约+refrence 行号；主线程集成与验收。

## 7. 测试与验收

真实 ST 文件 fixture 解析回归；prompt 快照测试（固定输入→拼装结果，逐项注释来源行号）；WI/正则/宏/群调度表驱动单测（sticky/budget/depth 边界）；端到端 WS 脚本（mock provider 回显流式）验证事件序列与落盘格式；最终用真实 ST 数据目录+真实 API key 完整对话/swipe/群聊/世界书验收。
