# 数据来源

`tts-providers.json` 的服务商名称、默认值、模型 / 音色名称按本地
`refrence/SillyTavern` v1.18.0（8172dcd）核对，适配器按接口行为重新实现。

Google Translate 语言名称 / ID 数据来自 SillyTavern 依赖的
[google-translate-api-x 10.7.2](https://unpkg.com/google-translate-api-x@10.7.2/lib/languages.cjs)。
该列表与参考保持兼容；列入翻译语言不代表 Google 为该语言提供朗读服务。
