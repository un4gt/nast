# 斜杠命令

输入框中以 `/` 开头即进入命令层，**发送前拦截**（未知命令不会触发模型）。

## 命令解析顺序

```
内置命令 → 自定义命令（展开为文本发送）→ 插件命令（透传服务端 Lua）→ 拦截并提示
```

命令名支持前缀缩写（如 `/d` → `/del`，有歧义时取注册顺序靠前者）。

## 内置命令（网页 + QQ 通用）

| 命令 | 行为 |
| --- | --- |
| `/help` | 帮助 |
| `/chars`（`/characters`） | 列出角色卡（★ 收藏） |
| `/char <片段>`（`/character`） | 切换角色。网页=切当前角色加载最近聊天；QQ=为当前来源切角色并开新聊天 |
| `/newchat [n]` | 新聊天（n=开场白序号，缺省随机） |
| `/worlds` | 列出世界书 |
| `/world <名称\|none>` | 绑定/解绑当前聊天世界书 |

## 网页端命令

| 命令 | 行为 |
| --- | --- |
| `/del <n>` | 删除第 n 条消息（0 起；缺省删最新） |
| `/swipe <left\|right>` | 切换/生成 swipe |
| `/regenerate` / `/continue` | 重生成 / 续写 |
| `/speak [voice="角色名"] <文本>` | 使用角色映射的音色朗读；不发送消息，不触发聊天模型；单聊和群聊均可用 |
| `/tts-stop` | 停止并清空朗读队列，取消当前生成余下的自动朗读 |
| `/impersonate` | 代入生成（结果填入输入框） |
| `/sys <text>` | 插入旁白系统消息（落盘不生成） |
| `/name <新名称>` | 重命名当前聊天 |
| `/go <片段>` | 切换到名称匹配的聊天 |
| `/persona <名称\|none>` | 绑定/解绑本聊天 persona |

## 自定义命令（`/` 用户可自定义）

设置 → **自定义命令**：每条 = 命令名 + 展开文本。

- 输入 `/命令名` → 展开文本作为你的消息发送（等效 ST QuickReply）
- 文本支持 `{{char}}` / `{{user}}` 宏（服务端生成时展开）
- **网页与 QQ 桥接共用同一份定义**（QQ 侧 60 秒缓存）
- 例：`开场` → 一段长开场白，QQ 里发 `/开场` 即可

## 插件命令

Lua 插件 `nast.register_command("upper", fn)` 注册的命令同样以 `/upper` 触发
（服务端执行，见[插件系统](../plugins.md)）。
