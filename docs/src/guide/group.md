# 群聊

## 建群与成员

- 侧栏「新建群组」：名称 + 成员多选（至少 2 名）
- 群设置（群聊区右上齿轮）：改群名、激活策略、卡片合并模式、允许自回复、
  成员管理（静音开关 / **健谈度滑条**（写回角色卡 talkativeness）/ 增删）、删除群

## 激活策略

| 策略 | 行为 |
| --- | --- |
| 自然（NATURAL） | @提及 + 健谈度掷骰 + 兜底，禁上一发言者连发 |
| 列表顺序（LIST） | 全部未静音成员按列表顺序依次回复 |
| 手动（MANUAL） | 随机一名成员 |
| 轮流（POOLED） | 自上次用户消息后未发言者优先 |

## 日常使用

- 发送消息 → 按策略激活的成员依次**流式逐字**回复（每成员独立气泡 + 思考链折叠）
- **触发单成员**：点顶部成员头像（静音成员带标记）
- **重生成**：按最后一批 `gen_id` 重新生成整批成员回复（无新用户消息）
- **候选与续写**：消息可切换既有候选、生成新候选和续写，保留成员身份及批次关系
- **自动对话**：启用后定时触发下一轮，可随时停止
- **群会话**：新建、切换、重命名、导入/导出、删除与会话世界书绑定；重命名/删除旧文件前备份，生成期间禁止修改会话
- 消息支持悬停复制 / 编辑 / 删除 / 双击编辑（与单聊同一气泡组件）
- 卡片合并模式：SWAP（当前成员卡）/ APPEND（合并全部成员卡，含 join 模板）/
  APPEND_DISABLED（合并含静音成员）

群聊文件平铺在 `group chats/<chat_id>.jsonl`，与 ST 布局一致；
每条群消息带 `original_avatar` / `force_avatar` / `gen_id` 批次标记。
