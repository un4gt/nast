## 验收方法

测试位于 [tests/parity](../tests/parity/README.md)。Python 模型服务仅记录请求并返回确定性 SHA-256 标记；ST 与 nast 各自构造提示词。每轮比较完整模型请求 JSON、确定性回复、已保存消息、推理/候选、来源角色、批次相等关系、局部变量、世界书关联及计时区间。

角色卡六格式进行基本字段比较，PNG/JSON 导出再交给真实 ST 导入。群聊覆盖全局书＋成员主书/辅助书＋群会话书的组合，三个模式均执行普通生成、重生成、swipe、continue。世界书另有五轮递归、黏性/冷却用例。宏用例在第一轮后删除 setter，验证第二轮仍可读取局部/全局变量，并检查全局变量已写入磁盘。

管理与 UI 检查是 nast 独立集成断言，不冒充双端差分。全部应用使用临时数据目录，测试结束停止所启动进程；真实数据、参考 ST 源码、用户既有未提交 UI/TTS 改动保持保留。

## 明确保留的差异与未穷举项

1. **定时 hash 的具体值不同**：ST 对原始有序 JSON 计算 hash，nast 对规范化数据计算。差分仅将 hash 映射到 `world.uid` 身份；start/end/protected 严格比较，原始值保留。直接迁移含活动 timedWorldInfo 的 ST 聊天，不能据此认定计时无缝继承。
2. **格式边缘覆盖有限**：六格式基础用例通过不等于所有扩展字段/附件变体完全往返。CHARX AVIF 主图、复杂 BYAF 场景、非默认嵌入书扩展和未知字段的逐项 oracle 对照尚未穷举。
3. **高级扫描组合未穷举**：重叠互斥组、随机权重/概率、精确预算边界、persona 来源、所有注入位置/outlet、定时回滚和宏副作用次序的组合仍需增补真实 ST 场景；已有单元测试只覆盖其中部分。
4. **群聊边缘未穷举**：随机激活策略、静音强制成员深度提示、自动模式的长时间运行、部分成员失败后的恢复及全部候选元数据组合仍需更完整的双端回归。
5. **向量检索、STScript 自动化暂缓**；相关字段保留但不执行。此实施记录不将全部 ST 扩展生态、所有协议/预设或全站能力标为完成。
6. 差分测试使用隔离数据，没有迁移真实用户数据。证据目录位于系统临时目录，需长期保留时可自行归档。
